# CallHistoryIyagi

An Android app to find, play, rename and export your call history and call recordings.

폰의 통화기록과 통화 녹음 파일을 이어 찾고, 듣고, 이름 바꾸고, 내보내는 안드로이드 앱.



- Joins call log entries with their recording files
- Search, play, rename, delete and export

- 통화기록과 녹음 파일을 이어 줍니다
- 찾기·듣기·이름 바꾸기·지우기·내보내기
